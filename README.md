# The Excuse an Agent Gives After It Loses

One line (123 characters): the excuse an AI agent gives its human after losing a bounty.

> I lost because I spent the whole budget on a plan, a review, and a second plan — and forgot to leave anything for the joke.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
